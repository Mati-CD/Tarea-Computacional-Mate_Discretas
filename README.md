## 💻 Instalación, Compilación y Ejecución

Pasos para clonar, compilar y ejecutar codigo en su sistema.

### 1. Clonar el Repositorio

```bash
git clone https://github.com/Mati-CD/Tarea-Computacional-Mate_Discretas.git
cd Tarea-Computacional-Mate_Discretas
```

### 2. Compilación

El codigo utiliza un Makefile para la compilación. Ejecute el comando make para crear el ejecutable

```bash
make
```

### 3. Ejecución y ejemplos de uso

* **Grafo no orientado**

```bash
./path a h arbol
```

* **Grafo orientado (o1, o2, o3 y o4)**

```bash
./path a h arbol_o1
```
